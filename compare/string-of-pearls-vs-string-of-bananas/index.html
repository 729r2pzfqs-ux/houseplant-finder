String of Pearls vs String of Bananas

String of bananas is the easier one - its beads hold more water and it grows faster. String of pearls shrivels at the first watering mistake.

String of Bananas is rated easy to care for, String of Pearls medium. If this is an early houseplant or the spot is hard to get right, start with the String of Bananas.

What they share: both are toxic to cats and dogs, both want bright indirect light, both take very low watering, both are happy in the same humidity and both stay small.

How to tell String of Pearls and String of Bananas apart

String of bananas is the easier one. Its curved, elongated beads hold more water and it grows noticeably faster, where string of pearls' round beads shrivel and drop at the first mistake. Neither is safe for pets.
