Burro's Tail vs String of Bananas

Burro's tail is pet-safe but drops beads if you brush it; string of bananas handles handling and grows faster, but is toxic to cats and dogs.

Burro's Tail is non-toxic to cats and dogs. String of Bananas is toxic to cats and dogs if chewed, so it needs a shelf pets cannot reach. String of Bananas is rated easy to care for, Burro's Tail medium. If this is an early houseplant or the spot is hard to get right, start with the String of Bananas.

What they share: both want bright indirect light, both take very low watering, both are happy in the same humidity and both stay small.

Key differences between Burro's Tail and String of Bananas

Burro's Tail is pet-safe, String of Bananas is not

Burro's Tail is non-toxic to cats and dogs. String of Bananas is toxic to cats and dogs if chewed, so it needs a shelf pets cannot reach.

String of Bananas is the easier plant

String of Bananas is rated easy to care for, Burro's Tail medium. If this is an early houseplant or the spot is hard to get right, start with the String of Bananas.

String of Bananas fills out faster

String of Bananas is a fast grower and gives you cuttings or a full pot sooner. Burro's Tail is slow, which means less pruning and repotting but a longer wait.

They come from different habitats

Burro's Tail originates in Mexico; String of Bananas in South Africa. Matching the original habitat is the quickest way to guess what each one wants indoors.

How to tell Burro's Tail and String of Bananas apart

Burro's tail has plump, tightly packed beads that fall off the moment you brush past, so hang it where nobody walks. String of bananas is far more robust to handling and grows faster, but is toxic to pets where burro's tail is not.
