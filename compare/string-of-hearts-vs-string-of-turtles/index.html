String of Hearts vs String of Turtles

String of hearts trails metres and grows fast; string of turtles creeps slowly and stays a tabletop plant. Both pet-safe; turtles wants more humidity.

String of Hearts is rated easy to care for, String of Turtles medium. If this is an early houseplant or the spot is hard to get right, start with the String of Hearts. String of Turtles needs medium indirect light (3/5) - near a bright window, out of direct sun. String of Hearts wants bright indirect light (4/5), beside a bright window, no midday sun on the leaves.

What they share: both are pet-safe and both stay small.

Key differences between String of Hearts and String of Turtles

String of Hearts is the easier plant

String of Hearts is rated easy to care for, String of Turtles medium. If this is an early houseplant or the spot is hard to get right, start with the String of Hearts.

String of Turtles copes with less light

String of Turtles needs medium indirect light (3/5) - near a bright window, out of direct sun. String of Hearts wants bright indirect light (4/5), beside a bright window, no midday sun on the leaves.

String of Turtles drinks more

String of Hearts wants very low watering (1/5) - water every 2-3 weeks, once the pot is bone dry. String of Turtles needs low watering (2/5): water when the top 3-5 cm of soil has dried out.

String of Turtles needs damper air

String of Turtles rates 3/5 for humidity - normal household humidity works. String of Hearts rates 2/5, so ordinary room air is fine.

String of Hearts fills out faster

String of Hearts is a fast grower and gives you cuttings or a full pot sooner. String of Turtles is slow, which means less pruning and repotting but a longer wait.

Different plant types: trailing vs succulent

String of Hearts is a trailing plant and String of Turtles is a succulent plant, so they fill different jobs in a room even when their care overlaps.

They come from different habitats

String of Hearts originates in South Africa; String of Turtles in Brazil. Matching the original habitat is the quickest way to guess what each one wants indoors.

How to tell String of Hearts and String of Turtles apart

String of hearts trails metres from a shelf and grows fast; string of turtles creeps slowly and stays short, so it is a tabletop plant rather than a hanging one. Both are pet-safe. Turtles wants a little more humidity.
